# Requirement traceability

Each row maps a requirement to the code that meets it, the test that checks it, and the evidence. Identifiers: `FR` = functional
requirement from the problem statement (FR-07 to FR-11 are quoted in the README), `OUT` = desired output, `NFR` = non-functional,
`PK` = rule from the organisers' pack README, `GL` = rule from the Participant Coding Guidelines v1.1. File paths are relative to
`FULL_CODE/`. `python scripts/quality_score.py` checks that every file and test named here exists.
